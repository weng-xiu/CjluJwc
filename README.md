“核心业务管理”与“师生互动服务”两大板块分类呈现。

---

## 一、核心业务管理模块（后台管理端）

| 功能分类 | 模块名称 | 主要功能说明 |
| :--- | :--- | :--- |
| **基础与资源管理** | 基础信息管理 | 管理学年、学期、院系、专业、班级、校区、教学楼、教室等基础教学资源 |
| | 教师信息管理 | 维护教师基本信息、任职信息、教学工作量统计、教师授课资格等 |
| | 教室资源管理 | 教室类型设置、教室容量管理、教室借用审批、多媒体设备维护记录 |
| **培养过程管理** | 培养方案管理 | 各专业人才培养方案制定与发布、教学计划编制、课程库维护、学分结构管理 |
| | 开课与排课管理 | 学期开课计划制定、教学任务下达、智能/手动排课、课表冲突检测、调停课申请与审批 |
| | 选课管理 | 选课轮次设置、选课规则配置（专业限制、跨年级/院系选课）、选课名单生成、选课抽签与退课处理 |
| **考核与评价管理** | 考试管理 | 期末考试、补考、重修考试的排考安排、监考教师分配、考场座位编排、考试冲突检测 |
| | 成绩管理 | 教师在线录入成绩、成绩复核与修改审批、成绩统计分析、绩点计算、不及格名单生成 |
| | 教学质量评价 | 期末学生评教问卷配置、评教进度控制、评教结果统计与分析、教学督导听课记录与反馈 |
| **学籍与学位管理** | 学籍管理 | 新生注册、在校生学籍维护、学籍异动（休学、复学、转学、退学）审批、学籍预警 |
| | 毕业与学位管理 | 毕业资格审核、学位资格审核、毕业证书与学位证书编号管理、毕业离校手续办理 |
| **系统与数据管理** | 用户与权限管理 | 角色权限分配（管理员、教学秘书、教师、学生），用户登录管理与操作日志记录 |
| | 数据对接与共享 | 与研究生系统、财务系统、一卡通系统、统一身份认证平台的数据交换与接口管理 |

## 二、师生互动服务模块（前台用户端）

| 用户角色 | 模块名称 | 主要功能说明 |
| :--- | :--- | :--- |
| **学生端** | 课表查询 | 查看学期个人课表（含时间、地点、任课教师），支持周视图/列表视图切换 |
| | 成绩查询 | 查询各学期课程成绩、绩点、学分获得情况，支持成绩单导出或在线打印 |
| | 选课中心 | 查看可选课程列表（含已选人数、剩余容量），在线选课/退课，查看选课结果 |
| | 考试安排 | 查询个人期末考试、补考的时间、地点、座位号，查看考试通知 |
| | 评教入口 | 在规定时间内对任课教师进行匿名评价，查看是否已完成评教（通常与查成绩/选课关联） |
| | 学籍服务 | 在线申请学籍异动（休学、复学等），核对个人学籍信息，查看学籍预警通知 |
| | 教务通知 | 查看教务处及学院发布的选课通知、考试通知、学籍管理通知等公告 |
| **教师端** | 个人课表 | 查看学期授课课表，支持调停课申请 |
| | 成绩录入 | 按照教学班录入学生成绩，支持暂存、提交、打印成绩单，提交成绩修改申请 |
| | 教学任务查询 | 查看所承担课程的教学任务、教学班名单、课程教学大纲 |
| | 监考安排 | 查看个人监考任务（时间、地点、科目） |
| | 评教结果查询 | 查看所授课程的评教反馈统计与评语（部分权限开放） |
| | 调停课申请 | 在线提交临时调课、停课或补课申请，并查看审批状态 |
